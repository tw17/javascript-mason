# 🎓 JavaScript Basics – Tutorial 1: Your First Program

Welcome to your first real JavaScript project! This guide will help you get started with programming using just **JavaScript** — no HTML or CSS needed.

---

## 🛠 What You’ll Need

- **VS Code** installed  
- **Node.js** installed  
- A folder to store your code (we’ll call it `js-fun`)

---

## Step 1: Create a New File

1. Open **VS Code**.
2. Create a new folder called `js-fun`.
3. Open that folder in VS Code.
4. Create a file inside it called `hello.js`.

---

## Step 2: Write Your First Line of Code

Open `hello.js` and type:

```javascript
console.log("Hello, world!");
```


## Step 3: Run Your Program
1. Open the Terminal in VS Code
2. From the menu: View → Terminal
3. In the terminal, type this command and press Enter: `node hello.js`

## Try This Challenge
Change your file to this:
```javascript
console.log("Hi, my name is Mason and I love coding!");
console.log("I'm learning JavaScript!");
```

## Bonus: Create Your Own Joke
1.	Create a new file called joke.js.
2.	Add this code:
```javascript
console.log("Why did the chicken cross the playground?");
console.log("To get to the other slide!");
```
3. Run it with `node joke.js`
